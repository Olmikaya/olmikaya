Measured contrast

WCAG 2.1

The palette is unusually well behaved. Nearly every text pairing clears AAA, which is what lets the site carry long-form reading without compromise.

One binding rule. Terracotta is a light-ground accent only. It must never be used as text or a meaningful mark on ink or green. On dark grounds use cream, off-white or sky.

Typography

Ovo and Inter

Ovo ships exactly one style: weight 400, no bold, no italic.

That single fact shapes the whole system. Ovo is a display face only — hierarchy comes from size, letterspacing, case and colour, never from weight. Putting a bold or italic tag inside Ovo-set text would make the browser synthesise a weight the typeface does not have, which reads as broken at editorial scale, so Ovo is scoped to headings, the wordmark and pull-quotes.

Inter carries everything you actually read: body copy, captions, metadata, navigation and UI. It has a real weight range and a true italic.

Scaffold note

Scaffold. Used anywhere a surface is structure rather than finished content, so placeholder work can never be mistaken for the real thing.

Motion

Almost none

Elements fade and rise a few pixels once, on entry. There is no parallax and nothing moves on its own.

The hidden state is scoped to a class the script adds, so with JavaScript disabled nothing is ever stranded invisible. Readers who ask for reduced motion get the finished state immediately, with transitions and the scroll observer both switched off.
